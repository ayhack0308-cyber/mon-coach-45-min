# MON COACH 45

Application web progressive (PWA) de musculation au poids du corps. Tous les fichiers sont à la racine (pas de sous-dossier) : `index.html`, `style.css`, `data.js`, `app.js`, `manifest.json`, `service-worker.js`, `icon.svg`, `icon-192.png`, `icon-512.png`.

## Publier sur GitHub Pages
1. Remplace les fichiers du dépôt (Add file → Upload files → Commit changes).
2. Settings → Pages → Deploy from a branch → main → / (root) → Save.
3. Ouvre l'adresse `https://TON-PSEUDO.github.io/NOM-DU-DEPOT/` avec Internet une première fois.

## Installer
- iPhone : Safari → Partager → Sur l'écran d'accueil.
- Android : Chrome → Installer l'application.

## Notes
- Données stockées uniquement sur l'appareil. Exporte une sauvegarde JSON régulièrement.
- Si une ancienne version s'affiche : ferme complètement l'app puis rouvre-la.
